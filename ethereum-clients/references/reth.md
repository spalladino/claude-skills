- Patch releases (e.g. `v2.8.1`, 2026-10-23) are cut on `release/*` branches and are NOT ancestors of `origin/main` (`git describe --tags origin/main` gives `v2.8.0-N`). To answer for a deployed release, `git show v2.8.1:<path>` instead of origin/main.

## 2. JSON-RPC server
- Servers: `crates/rpc/rpc-builder/src/lib.rs` (`RpcModuleBuilder`, `RpcServerConfig` {http, ws, ipc}, `TransportRpcModuleConfig`, `RpcRegistryInner`, `AuthRpcModule`); CLI -> config in `rpc-builder/src/config.rs` (`RethRpcServerConfig` impl for `RpcServerArgs`: `http_ws_server_builder`, `ipc_server_builder`, `eth_config`). HTTP and WS may share one port (jsonrpsee; if `--ws.port == --http.port` same server). Launch happens in `crates/node/builder/src/rpc.rs`.
- Transports are all OFF by default except IPC and auth: `--http` (false), `--ws` (false), IPC on (`--ipcdisable` false, `--ipcpath` `/tmp/reth.ipc` = `DEFAULT_IPC_ENDPOINT`, `--ipc.permissions`). `--dev` implies `--http`. Defaults: `--http.addr 127.0.0.1 --http.port 8545`, `--ws.addr 127.0.0.1 --ws.port 8546`, authrpc `127.0.0.1:8551`.
- Modules: `RethRpcModule` enum in `rpc-server-types/src/module.rs`: Admin, Debug, Eth, Net, Trace, Txpool, Web3, Rpc, Reth, Ots, Flashbots, Miner, Mev, Testing, Other(String). Selection: `RpcModuleSelection::{All, Standard, Selection(set)}`; **Standard = eth, net, web3** is the default for http/ws when `--http.api/--ws.api` is unset. `All` = everything except `testing` (testing needs explicit select). IPC default = `all_modules` (so `debug_`/`admin_` are available over IPC but not HTTP by default). `rpc_modules` method (`RPCApi`) lists enabled modules. Registration: `RpcRegistryInner::reth_methods` (match on `RethRpcModule`) and `register_*` in `rpc-builder/src/lib.rs`. `flashbots`/`testing`/`Other` register nothing there (added by node add-ons; `testing_buildBlockV1`, flag `--testing.skip-invalid-transactions`).
- Namespace traits (`rpc-api/src/`) -> impl (`rpc/src/`):
  - eth: trait `EthApiServer` in `rpc-eth-api/src/core.rs` (+ `ext.rs` L2 conditional tx, `bundle.rs` callBundle/sendBundle, `pubsub.rs` `eth_subscribe`, `filter.rs`); impl `rpc/src/eth/{core,filter,pubsub,bundle,sim_bundle}.rs` + helper traits in `rpc-eth-api/src/helpers/*`. Includes: `eth_getStorageValues`, `eth_getMultiProof`, `eth_getAccountInfo`, `eth_capabilities`, `eth_fillTransaction`, `eth_sendRawTransactionSync` (EIP-7966), `eth_callMany`, `eth_getBlockAccessList*` (EIP-7928, Amsterdam), `eth_simulateV1` (call.rs `simulate_v1`), `eth_getTransactionBySenderAndNonce`.
  - net: `net.rs` (version, peerCount, listening). web3: `web3.rs` (clientVersion only; `web3_sha3` is NOT defined - unverified, only `clientVersion` in trait).
  - debug: `rpc-api/src/debug.rs` -> `rpc/src/debug.rs` (`DebugApi`). Implemented: traceBlock*, traceTransaction, traceCall(+Many), executionWitness*, getRaw{Header,Block,Transaction(s),Receipts,BlockAccessList}, getBadBlocks, accountRange/accountAt, chainConfig, codeByHash, dbGet, stateRootWithUpdates, traceBadBlock, clearTxpool, `debug_subscribe`. **Many geth-only methods are stubs that return `null`/Ok(()) with no error** (chaindbCompact, chaindbProperty, dbAncient(s), dumpBlock, freeOSMemory, gcStats, memStats, setHead, storageRangeAt, ... see tail of `rpc/src/debug.rs`): do not assume a non-error response means data.
  - trace (OpenEthereum/Parity): `trace.rs` -> `rpc/src/trace.rs`: call, callMany, rawTransaction, replayBlockTransactions, replayTransaction, block, filter, get, transaction, transactionOpcodeGas, blockOpcodeGas. `trace_filter` limited by `--rpc.max-trace-filter-blocks` (default 100, `DEFAULT_MAX_TRACE_FILTER_BLOCKS`; error is InvalidParams with the limit in message).
  - txpool: `txpool.rs`: status, inspect, content, contentFrom (geth shape).
  - admin: `admin.rs`: addPeer, removePeer, add/removeTrustedPeer, banPeer/unbanPeer, peers, nodeInfo, clearTxpool. (No `admin_startRPC`, `admin_datadir`.)
  - ots (Otterscan): `otterscan.rs` (getApiLevel, getInternalOperations, searchTransactionsBefore/After, getContractCreator, ...). reth: `reth.rs` -> `rpc/src/reth.rs` (`reth_getBalanceChangesInBlock`, `reth_getBlockExecutionOutcome`, `reth_jit`; `reth_engine.rs` for engine-side reth_ subscriptions). miner/mev/validation(flashbots): `miner.rs`, `mev.rs`, `validation.rs`. anvil/hardhat traits exist for dev (`anvil.rs`, `hardhat.rs`).
- Server limits (`rpc_server.rs`, constants in `rpc-server-types/src/constants.rs`): `--rpc.max-request-size` 15 MB, `--rpc.max-response-size` 160 MB (alias `--rpc.returndata.limit`), `--rpc.max-connections` 500, `--rpc.max-subscriptions-per-connection` 1024, `--rpc.max-tracing-requests` = max(cpus-2, 2) (25 if unknown) (semaphore `BlockingTaskGuard` for debug_/trace_), `--rpc.max-blocking-io-requests` 256, `--rpc.proof-permits` 25 (concurrent getProof), `--rpc.disable-metrics`, `--http.corsdomain`, `--ws.origins`, `--http.api`, `--ws.api`, `--rpc.jwtsecret` (JWT for regular RPC).
- **JSON-RPC batch size: Reth sets NO explicit batch limit** (no batch config in `http_ws_server_builder`), so jsonrpsee's default (unlimited batch, bounded only by request/response size) applies (unverified against jsonrpsee version; check `Cargo.lock`). `max_batch_size` in `EthConfig` / `--txpool.max-batch-size` (default 1) is the pool *tx-insertion batcher* for sendRawTransaction, unrelated. `rpc-builder/src/rate_limiter.rs` (`RpcRequestRateLimiter`) exists but is not wired by default.
- Response over `--rpc.max-response-size`: jsonrpsee returns its own "Response is too big" error (jsonrpsee behaviour, code unverified).
- WS/IPC subscriptions (`rpc/src/eth/pubsub.rs`, `rpc-eth-api/src/pubsub.rs`): `eth_subscribe` kinds `newHeads`, `logs`, `newPendingTransactions` (param `true` = full tx objects), `syncing`, `transactionReceipts`; anything else -> invalid params "Unsupported subscription kind". Subscription ids: `EthSubscriptionIdProvider` (`rpc-eth-types/src/id_provider.rs`, hex like geth). Also `debug_subscribe`. Filters (`eth_newFilter` etc.): stale after 5 min without poll (`DEFAULT_STALE_FILTER_TTL`); unknown id -> code -32000 "filter not found".

## 4. Behaviours (what, where, defaults)
### Error codes and messages
- Central file: `rpc-eth-types/src/error/mod.rs`. Types: `EthApiError` (-> JSON-RPC error via `impl From<EthApiError> for ErrorObject`), `RpcInvalidTransactionError` (tx-execution/validation messages, mirrors geth strings), `RpcPoolError` (pool rejections, mirrors geth), `RevertError`, `EthFilterError` (in `rpc/src/eth/filter.rs`), `EthSimulateError` (`rpc-eth-types/src/simulate.rs`). Code enum `EthRpcErrorCode` is in alloy (`alloy-rpc-types-eth` `error.rs`): TransactionRejected -32003, ExecutionError 3, InvalidInput -32000, ResourceNotFound -32001, UnknownBlock -39001, PrunedHistory 4444, TransactionConfirmationTimeout 4.
- `RpcInvalidTransactionError::error_code`: Revert -> 3; InvalidChainId, GasTooLow, GasTooHigh, GasRequiredExceedsAllowance, NonceTooLow/High, FeeCapTooLow, FeeCapVeryHigh -> -32000; everything else (e.g. insufficient funds, intrinsic gas, tx type not supported) -> -32003.
- Messages: `execution reverted` (+ `: <decoded reason>` with `revert: ` prefix stripped; raw revert bytes hex in `error.data`) code 3; `nonce too low: next nonce {state}, tx nonce {tx}`; `nonce too high`; `insufficient funds for gas * price + value: have {balance} want {cost}`; `insufficient funds for transfer`; `gas required exceeds allowance ({gas_limit})`; `intrinsic gas too low`; `max fee per gas less than block base fee`; `max priority fee per gas higher than max fee per gas`; `max initcode size exceeded`; `sender is not an EOA`; `out of gas: gas required exceeds: N` (halts); `invalid chain ID`; `transaction type not supported`; blob: `blob transaction missing blob hashes`, `max fee per blob gas less than block blob gas fee`, `blob transaction exceeds max blobs per block; got N`.
- Pool errors (`RpcPoolError`, all code -32000 except overflow -32003): `already known`, `invalid sender`, `transaction underpriced`, `replacement transaction underpriced`, `txpool is full` (-32003), `exceeds block gas limit`, `exceeds max transaction gas limit`, `tx fee (X wei) exceeds the configured cap (Y wei)`, `oversized data: transaction size S, limit L`, `max initcode size exceeded`, `address already reserved`, `negative value`; wrapped `Eip4844`/`Eip7702` pool errors (below). Invalid tx input in sendRawTransaction: `empty transaction data`, `failed to decode signed transaction`, `invalid transaction signature` (invalid params -32602).
- Missing block: `block not found: {id}` code -32001 (`HeaderNotFound`, `ReceiptsNotFound`); `unknown block or tx index`; `header range not found...`; `finalized`/`safe` tag before known -> `HeaderNotFound(finalized|safe)` also -32001 (no -39001 here). `request beyond head block: requested N, head M` (-32602). `invalid block range` (-32602). Tracing: `transaction not found` / `block not found` / `genesis is not traceable`.
- Pruned history: `pruned history unavailable: requested N, earliest available M` code **4444** (`EthApiError::PrunedHistoryUnavailable`; also `ProviderError::StateAtBlockPruned` and `EthFilterError::ReceiptsUnavailable`, and `ExceedsMaxProofWindow` "distance to target block exceeds maximum proof window"). A pruned block body/state is NOT reported as `null`; mostly it is 4444 (header/hash lookups may still give null/`block not found`).
- Timeouts: `execution aborted (timeout = {0:?})` (`ExecutionTimedOut`, JS tracer); `eth_sendRawTransactionSync` timeout -> `TransactionConfirmationTimeout` code 4.

### eth_call / eth_estimateGas
- `rpc-eth-api/src/helpers/call.rs` (`prepare_call_env`, `Call`/`EthCall` traits) and `helpers/estimate.rs` (`estimate_gas_with`). Gas cap: `--rpc.gascap` default **50,000,000** (`RPC_DEFAULT_GAS_CAP`; 0 = unlimited). Requested gas above cap is silently clamped (debug log only); no gas given -> cap (and, if gasPrice>0, also the sender's balance-derived allowance via `caller_gas_allowance`, bounded by block gas limit).
- eth_call env: disables block gas limit check, EIP-3607 (EOA check), base-fee check, EIP-7825 tx gas cap (except Amsterdam/EIP-8037), balance checks/top-up, L2 fee charge; nonce is ignored; if gas price = 0 basefee is lowered to 0. EVM memory limit `--rpc.evm-memory-limit` default 2^32-1.
- Overrides: `EvmOverrides {state, block}` (`apply_state_overrides`, `apply_block_overrides` from alloy-evm/reth-rpc-eth-api). Errors: `account X has both 'state' and 'stateDiff'` (invalid params), `Invalid bytecode: ...`.
- estimateGas algorithm (geth-like): basic-transfer shortcut (21000 if recipient has no code and no input); run at highest limit = min(request gas, block gas limit/tx cap, `--rpc.gascap`, sender allowance); if revert/halt and request set gas or gasPrice, retry at max limit to tell OOG vs revert; then optimistic limit `(gas_used + refund + 2300) * 64/63`, then binary search with early stop when `(hi-lo)/hi < 0.015` (`ESTIMATE_GAS_ERROR_RATIO`) -> result is `highest_gas_limit` (may be ~1.5% above true minimum, differs from other clients' exact min). On revert: `execution reverted: ...` code 3 with data. `gas required exceeds allowance (N)` when balance-limited.
- eth_simulateV1: `helpers/call.rs::simulate_v1`, types `rpc-eth-types/src/simulate.rs`. `--rpc.max-simulate-blocks` default 256 (error `too many blocks`, code -38026; spec-style simulate codes -38010 nonce too low, -38011 nonce too high, -38012 basefee too low, -38013 intrinsic gas, -38014 insufficient funds, -38015 block gas limit, -38020/-38021 block number/timestamp order, -38024 sender not EOA, -38025 initcode size, -38022 move precompile to itself; block not found -32000; see `EthSimulateError::error_code`); state root computed only if `--rpc.compute-state-root-for-eth-simulate` (default false); shares `--rpc.gascap` across the whole simulation (error "Client adjustable limit reached"); empty calls -> `calls are empty.`; revert code 3 (`SIMULATE_REVERT_CODE`), VM error code -32015 (`SIMULATE_VM_ERROR_CODE`); `validation`, `traceTransfers`, `returnFullTransactions` supported (traceTransfers disabled where EIP-7708 active).
- eth_createAccessList, eth_callMany (`call_many`; errors `call_many error in bundle {i} and transaction {j}: ...`).

### eth_getLogs / filters
- `rpc/src/eth/filter.rs` (`logs_for_filter`, `get_logs_in_block_range`). Limits: `--rpc.max-blocks-per-filter` default **100,000** blocks (0 = unlimited; error `query exceeds max block range 100000`, -32602), `--rpc.max-logs-per-response` default **20,000** (0 = unlimited; **errors** `query exceeds max results 20000, retry with the range A-B` -32602, does not truncate). No wall-clock timeout on getLogs. `toBlock` > head -> error `block range extends beyond current head block: requested N, head M` (-32602; geth returns empty/clamps). `fromBlock > toBlock` -> `invalid block range params`. fromBlock below earliest retained block -> 4444 pruned error. By blockHash: unknown -> block not found; receipts pruned -> 4444. Uses bloom prefilter, header cache `MAX_HEADERS_RANGE=1000`, cached mode <=250 blocks, parallel above 1000 matches.
- `pending` as fromBlock: returns logs of locally built pending block only if ahead of head, else empty; `pending` toBlock without pending block resolves to head.

### Block tags
- Resolution: `crates/storage/storage-api/src/block_id.rs::convert_block_number`. latest = best (canonical head as per engine, after persistence/in-memory); earliest = `earliest_block_number()` = **first non-pruned block, not necessarily genesis** on pruned nodes; safe/finalized come from the last FCU (`engine_forkchoiceUpdated` safe/finalized hashes); before the CL provides them -> `HeaderNotFound` (-32001 `block not found: finalized`) rather than null/zero.
- `pending` (`rpc-eth-api/src/helpers/pending_block.rs` `LoadPendingBlock`): provider pending block if the CL supplied one, else Reth BUILDS a local pending block from the txpool on top of latest (cached until `expires_at`/head change). `--rpc.pending-block full|empty|none` (default **full**): `empty` = header only, `none` = no pending block (pending resolves to latest state / null block). `eth_getTransactionCount(pending)` uses pool nonces. feeHistory with `pending` newest is capped to latest.

### Fee history / gas price
- `helpers/fee.rs` (`fee_history`), `rpc-eth-types/src/fee_history.rs` (cache: `max_blocks = 1024+100`, percentile `resolution = 4`, so rewards are *approximated*), `gas_oracle.rs`. Max blocks per call: 1024 (`MAX_HEADER_HISTORY`; silently truncated), max 100 reward percentiles, percentiles must be ascending in [0,100] else `invalid reward percentiles`; newest above head -> `request beyond head block`.
- `eth_gasPrice` = base fee + suggested tip; `eth_maxPriorityFeePerGas` = oracle: last `--gpo.blocks` 20 blocks, lowest `SAMPLE_NUMBER`=3 tips per block, `--gpo.percentile` 60, ignore tips below `--gpo.ignoreprice` 2 wei, capped at `--gpo.maxprice` 500 gwei, `--gpo.default-suggested-fee` optional. Oracle caches per head hash. `eth_blobBaseFee`, `eth_baseFee` are exposed.

### eth_sendRawTransaction / pool
- Flow: `helpers/transaction.rs::send_raw_transaction` -> decode + recover sender -> `TransactionOrigin::Local` pool insert (`add_transaction`) -> returns hash; pool validation in `transaction-pool/src/validate/eth.rs` (`EthTransactionValidator`, `validate_stateless`, `validate_sender_nonce`, `validate_eip4844`). Optional forwarding to another node with `--rpc.forwarder <URL>` (`rpc-eth-types/src/tx_forward.rs`; builder-disallow list `--rpc.builder-disallow`). Because origin is Local, `--txpool.nolocals`/`--txpool.locals` change eviction/price exemption (`LocalTransactionConfig` in `config.rs`).
- Tx fee cap: `--rpc.txfeecap` default **1 ETH** (`DEFAULT_TX_FEE_CAP_WEI`, 0 = no cap) -> `tx fee (X wei) exceeds the configured cap (Y wei)`.
- `eth_sendRawTransactionSync`: timeout `--rpc.send-raw-transaction-sync-timeout` default 30 s (caller-supplied timeout is min'd with it).
- Pool config defaults (`transaction-pool/src/config.rs`, flags `args/txpool.rs`): subpools pending/basefee/queued/blob each `10_000` txs or `20` MB (`--txpool.{pending,basefee,queued,blobpool}-max-{count,size}`); `--txpool.max-account-slots` **16** per sender (per subpool); `--txpool.pricebump` **10** (%) for replacement (both max fee AND priority fee must rise by >= bump, else `replacement transaction underpriced`); `--blobpool.pricebump` **100** (%) (`REPLACE_BLOB_PRICE_BUMP`, needs to double); `--txpool.max-tx-input-bytes` 128 KiB (`DEFAULT_MAX_TX_INPUT_BYTES`; blobs/sidecar exempt); `--txpool.gas-limit` (enforced block gas limit); `--txpool.max-tx-gas` optional per-tx cap (EIP-7825 style); `--txpool.minimal-protocol-fee` (protocol min base fee), `--txpool.minimum-priority-fee` optional (error `transaction priority fee below minimum required priority fee`); queued txs expire after 3 h (`MAX_QUEUED_TRANSACTION_LIFETIME`, `maintain.rs`); tx with nonce == u64::MAX rejected (EIP-2681).
- Nonce gaps: allowed for regular txs (go to `queued` subpool, not propagated); nonce below account nonce -> `nonce too low`. Pending vs queued vs basefee-pool semantics in `pool/txpool.rs`/`pool/parked.rs` (`SubPool`).
- Blob txs (type 3): `Eip4844PoolTransactionError` in `transaction-pool/src/error.rs`: `blob sidecar not found for EIP4844 transaction`, `blobless blob transaction`, `too many blobs in transaction: have X, permitted Y` (limit from fork blob params: `fork_tracker.max_blob_count()`), `nonce too high` (`Eip4844NonceGap`: **blob txs with a nonce gap are rejected, never queued**), `unexpected eip-7594 sidecar before osaka`, `unexpected eip-4844 sidecar after osaka` (post-Osaka: only EIP-7594 cell-proof sidecars accepted unless `--rpc.force-blob-sidecar-upcasting`), `eip-7594 sidecar disallowed`, invalid KZG proof. Blob store on disk (`blobstore/disk.rs`, cache `--txpool.blob-cache-size`, `--txpool.max-cached-entries` 100); `--txpool.disable-blobs-support`. A sender cannot hold both blob and non-blob txs (`address already reserved` / `ExistingConflictingTransactionType`). Rejected before Cancun with `transaction type not supported`.
- Set-code txs (type 4): `Eip7702PoolTransactionError`: `no items in authorization list for EIP7702 transaction`, `gapped-nonce tx from delegated accounts` (accounts with delegation can't queue nonce gaps), `in-flight transaction limit reached for delegated accounts` (`DEFAULT_MAX_INFLIGHT_DELEGATED_SLOTS` = 1), `authority already reserved`. Sender with delegated code is allowed as EOA (EIP-3607 exception).

### debug_trace* / trace_*
- Tracers (geth `GethDebugBuiltInTracerType`): callTracer, flatCallTracer, prestateTracer, 4byteTracer, muxTracer, noopTracer, default struct logger; JS tracers only if built with feature `js-tracer` (default timeout 5 s, `DEFAULT_JS_TRACER_TIMEOUT`, option `timeout`); otherwise error `unsupported tracer` / JS tracing disabled. Bad config -> `invalid tracer config`. Concurrency gated by `--rpc.max-tracing-requests`. `debug_traceCall` supports `stateOverrides`, `blockOverrides`, `txIndex`. Tracing a historical block needs state (pruned -> 4444). Parity types: `trace_*` use `TraceType`s trace/vmTrace/stateDiff.
- `debug_executionWitness` (stateless witness) exists and is supported; `debug_getRawReceipts` etc. are Reth-specific names matching execution-apis debug.

### Pruning / history expiry
- Default (no flags) = **archive**: all history, receipts, state history kept. `--full`: `PruneModes` in `args/pruning.rs::DefaultPruningValues`: sender_recovery Full, receipts/account_history/storage_history `Distance(MINIMUM_UNWIND_SAFE_DISTANCE = 10,064)` blocks, tx lookup kept, block bodies pruned before the Paris/merge block (`full_bodies_history_use_pre_merge`). `--minimal`: tx lookup Full, receipts Distance(`MINIMUM_DISTANCE` = 64), account/storage/bodies Distance(10,064). Per-segment: `--prune.{sender-recovery,transaction-lookup,receipts,account-history,storage-history,bodies}.{full,distance,before}`, `--prune.block-interval`, `--prune.bodies.pre-merge`. Constants: `crates/prune/types/src/target.rs`. Pruner: `crates/prune/prune/` (working tree has user edits here: read origin/main).
- Effects on RPC: logs/receipts/block bodies/historical state older than the retained window -> code 4444 errors (see above), `earliest` tag = first retained block, `eth_getProof` allowed only within `--rpc.eth-proof-window` blocks of tip: **default 0 = latest only** (hard max `MAX_ETH_PROOF_WINDOW` = 28 days of blocks ~1.2M); older -> `distance to target block exceeds maximum proof window`. Historical state reads on non-archive nodes only go back to the retained account/storage history window (+ `StateAtBlockPruned`).
- Pre-merge history import: `reth import-era`, `--era.*` args (`args/era.rs`); snapshots via `reth download` (`crates/cli/commands/src/download/`).

### Caches / misc
- `--rpc-cache.max-blocks` 1000 / `max-receipts` 500 / `max-headers` 1000 / `max-bals` 1000 / bytes 2 GiB blocks, 1 GiB receipts, 500 MiB BALs, concurrent DB requests 512 (`rpc-eth-types/src/cache/config.rs`, flags `args/rpc_state_cache.rs`).
- Metrics: Prometheus via `--metrics`; RPC method metrics on by default (`--rpc.disable-metrics`).

## 5. Quirks / deviations
- No default HTTP/WS; HTTP default namespaces only eth/net/web3; IPC exposes everything incl. debug/admin.
- `eth_getLogs` errors instead of truncating when over 20k logs, and errors when `toBlock` > head (geth tolerates); limit codes are -32602 not -32005.
- `estimateGas` may overshoot minimum by up to ~1.5% (binary-search tolerance) vs exact search in other clients; revert returns code 3 plus data like geth.
- Pruned data yields code **4444** with "pruned history unavailable" (EIP-4444 style) rather than null/missing trie node.
- Blob txs with nonce gaps rejected at pool; blob replacement needs +100% (geth: +100% as well on fee fields; others differ).
- `finalized`/`safe` before CL has set them: error -32001 `block not found`, not null.
- `eth_getProof` window default 0 (latest-only) unlike geth's 128-block state window.
- Many `debug_*` geth-only methods are no-op stubs returning null/OK.
- `eth_call` ignores the base fee and nonce; calls cap gas at `--rpc.gascap` 50M silently.
- Pending block is locally built (`full` mode) unless CL provides one; `pending` state reads include mempool txs.
- Hive known failures for RPC compliance: `.github/scripts/hive/expected_failures.yaml` (rpc-compat: debug_getRaw* invalid-number, `eth_getStorageAt` invalid key, legacy receipt cases) and `ignored_tests.yaml`.
