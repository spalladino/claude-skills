## 1. Orientation

- Binary entrypoint: `cmd/geth/main.go` (`main` -> `app.Run`; `geth()` starts the node; `makeFullNode` in `cmd/geth/config.go` wires everything). Other cmds: `cmd/evm`, `cmd/workload`, `cmd/devp2p`, `cmd/era`, `cmd/abigen`, `cmd/keeper`.
- CLI flag definitions + defaults: `cmd/utils/flags.go` (cli.Flag vars such as `RPCGlobalGasCapFlag`; `Set*Config` funcs apply them, e.g. `SetEthConfig`, `setGPO`, `setTxPool`). Flag defaults come from structs, not literals:
  - `node/defaults.go` `DefaultConfig` (ports, HTTP/WS modules, batch limits, body limit, P2P).
  - `eth/ethconfig/config.go` `Defaults` (RPC gas cap, EVM timeout, tx fee cap, history, log limits, GPO via `FullNodeGPO`).
  - `rpc/http.go` `DefaultHTTPTimeouts`; `core/txpool/legacypool` `DefaultConfig`; `core/txpool/blobpool/config.go` `DefaultConfig`; `miner/miner.go` `DefaultConfig`.
  - `cmd/geth/config.go` `defaultNodeConfig` adds `eth` to `HTTPModules`/`WSModules` (so default HTTP/WS modules are `net,web3,eth`) and `--config` TOML loading (`dumpconfig`).
- Key dirs: `rpc/` (generic JSON-RPC server/client), `node/` (HTTP/WS/IPC stacks, JWT, `admin`/`web3`/`debug` handlers), `internal/ethapi/` (eth_* impl, `simulate.go`, `override/`, `errors.go`), `eth/` (backend, `api_backend.go`, `api_debug.go`, `api_admin.go`, `api_miner.go`), `eth/catalyst/` (Engine API), `eth/filters/` (logs, subscriptions), `eth/tracers/` (debug_trace*), `eth/gasestimator`, `eth/gasprice`, `core/txpool/{legacypool,blobpool,locals}`, `core/history` (history pruning), `miner/` (pending block, payload building), `beacon/engine` (Engine types/errors), `graphql/`, `ethclient/`, `cmd/workload` (RPC conformance workloads), `tests/` (consensus fixtures).
- Defaults: mainnet; `--syncmode snap`; path state scheme; `--gcmode full`; `--dev` = simulated beacon (`--dev.period`, `--dev.gaslimit`; sets miner gasprice to 1 wei unless set, `cmd/utils/flags.go`). Networks: `--mainnet`, `--sepolia`, `--hoodi`. Fork overrides: `--override.osaka|amsterdam|bpo1|bpo2|ubt|genesis`.
- This master is ahead of mainnet forks: Osaka/BPO1-2, Amsterdam/BPO3-5/Bogota fork names, snap/2, sparse blobpool (EIP-8070), UBT/binary trie are all present in code.

## 2. JSON-RPC server

- Generic server: `rpc/server.go` (`Server`, `RegisterName`, `SetBatchLimits`), `rpc/handler.go` (dispatch, batch limits, timeouts), `rpc/service.go` (reflection: exported method `FooBar` on namespace `x` -> `x_fooBar`; a method returning `*rpc.Subscription` becomes `x_subscribe`/`x_unsubscribe` kind), `rpc/http.go`, `rpc/websocket.go`, `rpc/ipc*.go`, `rpc/json.go`, `rpc/errors.go`, `rpc/types.go` (`BlockNumber`, `BlockNumberOrHash`).
- Node wiring: `node/node.go` `startRPC` (builds 4 listeners: legacy HTTP, WS, authenticated HTTP+WS, IPC; in-proc for the console), `node/rpcstack.go` (`httpServer`, `enableRPC`, `enableWS`, CORS/vhost handlers, gzip, `RegisterApis`, WS handler stack), `node/jwt_handler.go`, `node/endpoints.go` (`StartHTTPEndpoint`), `node/defaults.go`.
- Module filtering: only modules named in `--http.api`/`--ws.api` are served on the unauthenticated ports (`RegisterApis` in `node/rpcstack.go`); `rpc` namespace (`rpc_modules`) always present (`rpc/server.go`). Calls to an unexposed method give `-32601 the method X does not exist/is not available`.
- Default ports/hosts: HTTP `localhost:8545` (only if `--http`), WS `localhost:8546` (only if `--ws`), authrpc `localhost:8551` (always when any authenticated API registered), IPC `geth.ipc` (`--ipcdisable`, `--ipcpath`), P2P `:30303`. Flags: `--http.addr/port/api/corsdomain/vhosts/rpcprefix`, `--ws.addr/port/api/origins/rpcprefix`, `--graphql`.
- Namespaces and where handlers live (registration points):
  - `eth` (core): `internal/ethapi/backend.go` `GetAPIs` -> `EthereumAPI` (gasPrice, maxPriorityFeePerGas, feeHistory, blobBaseFee, baseFee, syncing), `BlockChainAPI` (blocks, balance, code, storage, getProof, call, estimateGas, simulateV1, createAccessList, config (EIP-7910), capabilities, getBlockReceipts, getStorageValues), `TransactionAPI` (tx lookup, sendRawTransaction, sendRawTransactionSync, sendTransaction, sign*, resend), `EthereumAccountAPI` (`eth_accounts`). All in `internal/ethapi/api.go` (+ `capabilities.go`).
  - `eth` filters: `cmd/utils/flags.go` `RegisterFilterAPI` -> `eth/filters/api.go` `FilterAPI` (getLogs, newFilter, getFilterChanges, getFilterLogs, uninstallFilter, newBlockFilter, newPendingTransactionFilter, subscriptions).
  - `eth` syncing subscription: `eth/downloader/api.go` `DownloaderAPI` (registered in `eth/backend.go` `Ethereum.APIs`).
  - `txpool`: `internal/ethapi/api.go` `TxPoolAPI` (content, contentFrom, status, inspect).
  - `net`: `internal/ethapi/api.go` `NetAPI` (version, listening, peerCount). `web3`: `node/api.go` `web3API` (clientVersion, sha3).
  - `debug`: split across `eth/api_debug.go` `DebugAPI` (dumpBlock, preimage, getBadBlocks, accountRange, storageRangeAt, getModifiedAccounts*, executionWitness, clearTxpool, setTrieFlushInterval), `eth/api_debug_replay.go` (replayBadBlock), `internal/ethapi/api.go` `DebugAPI` (getRawHeader/Block/Receipts/Transaction, printBlock, chaindbProperty/Compact, setHead), `internal/ethapi/dbapi.go` (dbGet, dbAncient(s)), `eth/tracers/api.go` (trace*), `internal/debug/api.go` `HandlerT` (profiling, verbosity, vmodule, memStats, stacks), `node/api.go` `p2pDebugAPI`.
  - `admin`: `node/api.go` `adminAPI` (addPeer, removePeer, trusted peers, peers, nodeInfo, datadir, startHTTP/WS, peerEvents) + `eth/api_admin.go` (exportChain, importChain). `miner`: `eth/api_miner.go` (setExtra, setGasPrice, setGasLimit). Note `miner_setGasPrice` also updates the txpool min tip (`eth/api_miner.go`).
  - `engine` (authenticated): `eth/catalyst/api.go` (section 3). `testing` (`testing_buildBlockV1`, `testing_commitBlockV1`): `eth/catalyst/api_testing.go`, registered unauthenticated in `catalyst.Register` and in dev mode (unverified whether intended for prod exposure; it is only reachable if `testing` is in `--http.api`). `dev` (dev mode only): `eth/catalyst/simulated_beacon_api.go`.
  - `personal`: removed; only `eth_sendTransaction`/`eth_sign*` against keystore accounts remain.
  - `graphql`: `graphql/` served at `/graphql` on the HTTP port with `--graphql`.
- Request limits (non-authenticated; `node/defaults.go`, flags in `cmd/utils/flags.go`):
  - `--rpc.batch-request-limit` 1000 items; over -> single `-32600 batch too large` response (`rpc/handler.go`, `rpc/errors.go` `errMsgBatchTooLarge`).
  - `--rpc.batch-response-max-size` 25,000,000 bytes; once exceeded remaining items get `-32003 response too large` (`errcodeResponseTooLarge`). Applies to non-batch responses too (`handler.go` checks `batchResponseMaxSize != 0`).
  - `--rpc.http-body-limit` 5 MiB (`HTTPBodyLimit`, `rpc/http.go` `defaultBodyLimit`); larger Content-Length -> HTTP 413 `content length too large`. Non-JSON content-type -> 415. PUT/DELETE -> 405.
  - WS read limit 32 MiB (`rpc/websocket.go` `wsDefaultReadLimit`); ping every 30s, pong timeout 30s.
  - HTTP timeouts `rpc.DefaultHTTPTimeouts`: read 30s, read header 30s, write 30s, idle 120s. The internal request timeout is `WriteTimeout - 100ms` (`rpc/http.go` `ContextRequestTimeout`), after which handler returns `-32002 request timed out` (`errMsgTimeout`). No explicit timeout on WS/IPC requests.
  - Authenticated (engine) port: batch 2000 items, response 250 MB, body 128 MiB, gzip off, not configurable (`node/defaults.go` `engineAPIBatchItemLimit`, etc.).
- Error code table (`rpc/errors.go`): parse -32700, invalid request -32600, method not found -32601 (also `notifications not supported`), invalid params -32602, internal/panic -32603, default server error -32000, timeout -32002, response too large -32003. JSON-RPC errors are returned HTTP 200 with an error body (except the HTTP-level 401/405/413/415 above).
- Subscriptions (WS/IPC only; over HTTP -> `-32601 notifications not supported`): `eth_subscribe` kinds `newHeads`, `logs`, `newPendingTransactions` (optional `fullTx` bool), `transactionReceipts` (`maxTxHashes` = 200), `syncing`; `debug_subscribe traceChain`; `admin_subscribe peerEvents`. Code: `eth/filters/api.go`, `eth/filters/filter_system.go` (`EventSystem`). Pending-logs subscription is rejected: `invalid params: pending logs are not supported` (-32602). Polling filters (`eth_newFilter` etc.) expire after 5 min of inactivity (`filter_system.go` `Config.Timeout`, `timeoutLoop`).

## 3. Engine API

- Code: `eth/catalyst/api.go` (`ConsensusAPI`; `Register` adds it with `Authenticated: true`), `eth/catalyst/witness.go` (`*WithWitnessV*`, `executeStatelessPayloadV1-5` — stateless/witness variants, non-standard), `eth/catalyst/queue.go` (payload/header caches), types and errors in `beacon/engine/` (`types.go`, `errors.go`, `gen_*.go`). Simulated-beacon dev mode: `eth/catalyst/simulated_beacon.go`. With `--beacon.api` (blsync) the engine is served in-proc only (`cmd/geth/config.go`).
- JWT: `node/jwt_handler.go` (HS256, `iat` must be within +-60s `jwtExpiryTimeout`; error text `token is expired`, HTTP 401), secret via `--authrpc.jwtsecret` (32-byte hex file; `node/node.go` `ObtainJWTSecret`). If the flag is unset, secret is read/created at `<datadir>/jwtsecret` (`datadirJWTKey` in `node/config.go`); an ephemeral secret is logged if no datadir. Flags: `--authrpc.addr` (localhost), `--authrpc.port` (8551), `--authrpc.vhosts` (localhost). Authenticated server only serves modules `eth` and `engine` (`node/defaults.go` `DefaultAuthModules`), CORS/origins `localhost`.
- Methods (each `XxxVn` Go method -> `engine_xxxVn`; `ExchangeCapabilities` builds the list by reflection over all exported methods of `ConsensusAPI`, so the capability list includes the witness variants and `engine_hasBlobs`):
  - `newPayloadV1..V5` (V3 Cancun; V4 Prague/Osaka/BPO1-2; V5 Amsterdam/BPO3-5/Bogota). Wrong version for fork -> `-38005 Unsupported fork`; missing/extra fields -> `-32602 Invalid parameters` (e.g. `nil versionedHashes post-cancun`, `slotNumber not supported pre-amsterdam`).
  - `forkchoiceUpdatedV1..V4` (V4 = Amsterdam, adds `slotNumber`; second arg `custodyColumns` bitmap). Bad attributes -> `-38003 Invalid payload attributes`; bad finalized/safe -> `-38002 Invalid forkchoice state` (`final block not available in database`, `...not in canonical chain`).
  - `getPayloadV1..V6` (V2 Paris/Shanghai, V3 Cancun, V4 Prague, V5 Osaka/BPO1-2 (cell proofs), V6 Amsterdam+). Unknown id -> `-38001 Unknown payload`.
  - `getBlobsV1` (Cancun/Prague only; after Osaka -> `-38005`), `getBlobsV2` (all-or-nothing, returns `null` if any missing or pre-Osaka), `getBlobsV3` (partial, `null` entries), `getBlobsV4` (cell-level with indices bitarray, `BlobCellsAndProofsV1`; calling `exchangeCapabilities` with `engine_getBlobsV4` flips blob cache into cell mode). Request > 128 hashes -> `-38004 Too large request`. Also `engine_hasBlobs`.
  - `getPayloadBodiesByHashV1/V2`, `getPayloadBodiesByRangeV1/V2` (start/count 0 -> -32602; count > 1024 -> -38004; range clamped to head), `exchangeCapabilities`, `getClientVersionV1`, `exchangeTransitionConfigurationV1` (deprecated, still present).
- Behaviours: invalid payload is returned as `status: INVALID` with `latestValidHash` + `validationError` (not a JSON-RPC error); unknown parent/head -> `SYNCING` (triggers `Downloader().BeaconSync`) or `ACCEPTED` (side-chain parent without state); `delayPayloadImport`, `checkInvalidAncestor`, `invalidBlockHitEviction` = 128 re-attempts before retrying a known-bad block. FCU to a head with `HeadBlockHash == 0x0` -> `INVALID`. FCU backwards to a non-finalized ancestor does reorg only if synced and depth <= `--engine.maxreorgdepth` (default 32, 0 = unlimited) else `-38006 Too deep reorg`; FCU to a finalized ancestor is silently `VALID` (no-op).
- Quirk: the TODO in `ForkchoiceUpdatedV3/V4` notes that on bad payload attributes the FCU state update is NOT applied (spec says it should be).

## 4. Common behaviours

### Error codes and messages
- `internal/ethapi/errors.go`: `revertError` code **3**, message `execution reverted` or `execution reverted: <abi-decoded reason>`, `data` = hex of full revert bytes (`newRevertError`). Used by `eth_call`, `eth_estimateGas`, `eth_createAccessList`.
- Tx validation codes (`txValidationError`, used by simulate; `eth_sendRawTransaction` returns the plain pool error with code -32000): nonce too low -38010, nonce too high -38011, basefee/feecap too low -38012, intrinsic gas -38013, insufficient funds -38014, block gas limit reached -38015, invalid block number -38020, invalid timestamp -38021, sender not EOA -38024, init code too large -38025, client limit exceeded -38026, VM error -32015, internal -32603.
- Messages from `core/error.go` and `core/txpool/errors.go`: `nonce too low` (pool appends `: next nonce N, tx nonce M`), `nonce too high`, `insufficient funds for gas * price + value` (pool appends `balance, queued cost, tx cost, overshot`), `already known`, `transaction underpriced`, `replacement transaction underpriced`, `transaction gas price below minimum`, `txpool is full`, `exceeds block gas limit`, `oversized data`, `account limit exceeded`, `in-flight transaction limit reached for delegated accounts`, `gapped-nonce tx from delegated accounts`, `authority already reserved`, `future transaction tries to replace pending`, `transaction blob limit exceeded`.
- `header not found`: `eth/api_backend.go` `StateAndHeaderByNumber` (state methods/eth_call on a future/unknown block number); hash variants say `header for hash not found`. `eth_getBlockByNumber/Hash` and tx/receipt lookups return `null` for unknown. `safe block not found` / `finalized block not found` (`ethapi.ErrSafeBlockNotFound`/`ErrFinalizedBlockNotFound`) when the CL has not set them yet. `hash is not currently canonical` for `requireCanonical`.
- `pruned history unavailable` code **4444** (`core/history/historymode.go` `PrunedHistoryError`): returned for block/header/body/log access below `HistoryPruningCutoff()` (`eth/api_backend.go`, `eth/filters`). State older than retention: `state not available` (`triedb/database` `ErrStateUnavailable`) or `historical state ... ` errors (`core/state/database_history.go`).
- `transaction indexing is in progress` (`TxIndexingError`, code -32000) from `eth_getTransactionByHash/Receipt` when the tx indexer has not finished and tx is not found.
- Block param parsing (`rpc/types.go`): tags `latest|earliest|pending|safe|finalized` or `0x` hex quantity only (decimal strings error with hex decode errors); `> MaxInt64` -> `block number larger than int64`. `BlockNumberOrHash` object with both fields -> `cannot specify both BlockHash and BlockNumber, choose one or the other`.

### Block tags / "pending"
- `latest` = `blockchain.CurrentBlock()` head; `safe`/`finalized` come from last FCU (`SetSafe`/`SetFinalized`), error until first set. `earliest` = `HistoryPruningCutoff()` (NOT genesis when history is pruned) — a deviation from spec (`eth/api_backend.go` `HeaderByNumber`).
- `pending` = synthetic block built locally by `miner/miner.go` `getPending` from the txpool on top of head (fee recipient `--miner.pending.feeRecipient`, zero random, timestamp = now or parent+1), cached `pendingTTL` = 2s (`miner/pending.go`). Not a consensus-client proposal. `pending` works for eth_getBlockByNumber, eth_getBlockReceipts, eth_call/state reads (state of the pending block), and `eth_getTransactionCount` (uses `txPool.PoolNonce`, `GetPoolNonce`). Errors `pending block is not available`, `pending state is not available`. `eth_getLogs`/log subscriptions with pending -> `pending logs are not supported`; `debug_trace*` on pending -> `tracing on top of pending is not supported`.

### eth_call / eth_estimateGas
- `internal/ethapi/api.go`: `BlockChainAPI.Call` -> `DoCall` -> `doCall`; `EstimateGas` -> `DoEstimateGas` -> `eth/gasestimator/gasestimator.go` `Estimate`. Default block: `latest`.
- Gas cap `--rpc.gascap` default **50,000,000** (0 = unlimited; `ethconfig.Defaults.RPCGasCap`). Caller `gas` above cap is silently lowered (log warn); missing `gas` = cap (or MaxUint64/2 if cap 0) (`TransactionArgs.CallDefaults`). Osaka tx gas cap 2^24 (`params.MaxTxGas`) is applied in estimate before Amsterdam; eth_call skips the execution-gas-cap check (`SkipExecutionGasCapCheck`).
- EVM timeout `--rpc.evmtimeout` default **5s** applies to `eth_call` (error `execution aborted (timeout = 5s)`); `eth_estimateGas` has no separate timeout (only ctx/HTTP timeout).
- eth_call runs with `NoBaseFee: true`; if `gasPrice`/`maxFeePerGas` is 0, base fee is zeroed so no balance check applies. Mixed `gasPrice` + `maxFeePerGas/maxPriorityFeePerGas` -> `both gasPrice and (maxFeePerGas or maxPriorityFeePerGas) specified`; chainId mismatch -> `chainId does not match node's (have=.., want=..)`; both `data` and `input` unequal -> error.
- Estimate algorithm: hi = tx gas (if >= 21000) else block gas limit, lowered to cap and to balance/feeCap allowance; fast path 21000 for plain transfers to non-contracts; run at hi (fail -> revert error with data or `gas required exceeds allowance (N)`); lo = usedGas-1; one optimistic try at `(MaxUsedGas + CallStipend) * 64/63`; then binary search stopping when `(hi-lo)/hi < 0.015` (`estimateGasErrorRatio`), so results can overshoot the minimum by up to ~1.5%. Reverts return code 3 + data. Blob gas not computed.
- Overrides: `internal/ethapi/override/override.go`. State override per account: `nonce`, `code`, `balance`, `state` (replace all storage), `stateDiff`, `movePrecompileToAddress`; `state`+`stateDiff` together -> error. Block overrides struct `BlockOverrides` (number, difficulty, time, gasLimit, feeRecipient, prevRandao, baseFeePerGas, blobBaseFee, withdrawals...). Supported in `eth_call`, `eth_estimateGas`, `eth_createAccessList`, `debug_traceCall`, `eth_simulateV1`.

### eth_getLogs and filters
- `eth/filters/api.go` `GetLogs` -> `filter.go` `Filter.Logs`/`rangeLogs`; indexed search via `core/filtermaps` (log index), falls back to bloom/unindexed scan outside the index.
- No default block-range limit: `--rpc.rangelimit` default **0** (unlimited); when set exceeding gives `-32602 exceed maximum block range N`. No cap on number of returned logs and no explicit query timeout (only HTTP write timeout / ctx cancel) — big ranges are the main DoS surface.
- `--rpc.logquerylimit` default **1000** = max addresses and max alternatives per topic position (`exceed max addresses or topics per search position`); more than 4 topic positions -> `exceed max topics`.
- Errors: `invalid block range params` (from > to, both non-negative), `can't specify fromBlock/toBlock with blockHash`, `unknown block` (blockHash not found), `pruned history unavailable` (4444) for from-block or blockHash before history cutoff, `finalized header not found`, `safe header not found`, `pending logs are not supported`. `toBlock` beyond head is clamped to head (resolves `latest` each iteration). `earliest` = cutoff.
- Log index retention `--history.logs` default **2,350,000** blocks (~1 year; 0 = whole chain; `--history.logs.disable` turns it off). Log cache `--cache.blocklogs` 32 blocks (`FilterLogCacheSize`).

### Gas price oracle / fee history
- `eth/gasprice/gasprice.go` `Oracle.SuggestTipCap`; `eth/gasprice/feehistory.go` `FeeHistory`. Defaults (`ethconfig.FullNodeGPO`): `--gpo.blocks` 20, `--gpo.percentile` 60, `--gpo.maxprice` 500 gwei, `--gpo.ignoreprice` 2 wei, max header/block history 1024. Samples the 3 lowest-tip txs per block (`sampleNumber`) excluding miner's own txs and tips under ignoreprice, takes percentile, caps at maxprice; seeded with `miner.gasprice`. `eth_gasPrice` = suggested tip + head basefee (head's, not next block's); `eth_maxPriorityFeePerGas` = tip only. Non-standard: `eth_baseFee` (next block base fee), `eth_blobBaseFee`.
- `eth_feeHistory`: `blockCount` > 1024 silently truncated (log warn "Sanitizing fee history length"); count 0 returns zeros/no data; `lastBlock` beyond head -> `request beyond head block`; bad percentile -> `invalid reward percentile`; includes blob fields (`baseFeePerBlobGas`, `blobGasUsedRatio`) post-Cancun; `pending` allowed as lastBlock.

### eth_sendRawTransaction and tx fee cap
- `TransactionAPI.SendRawTransaction` -> `SubmitTransaction` (`internal/ethapi/api.go`): (1) `checkTxFee`: `gasPrice (feeCap) * gas` > `--rpc.txfeecap` (default **1 ether**, 0 = no cap) -> `tx fee (X ether) exceeds the configured cap (1.00 ether)`; (2) non-EIP-155 legacy txs rejected unless `--rpc.allow-unprotected-txs`: `only replay-protected (EIP-155) transactions allowed over RPC`; (3) `EthAPIBackend.SendTx` -> `txPool.Add`. Returns tx hash only after pool admission (no wait).
- Blob tx sidecars: post-Osaka only version-1 (cell proof) sidecars accepted; v0 sidecars are auto-converted at RPC (`currentBlobSidecarVersion`, `sc.ToV1()`; marked TODO remove in 1.17.x). Pool rejects `Wrong sidecar format`.
- Local tracker (`core/txpool/locals`, enabled unless `--txpool.nolocals`): txs submitted via RPC that fail with a *temporary* reject (`IsTemporaryReject`: underpriced, pool overflow, delegated-account limits, future-replace-pending) return **success** to the client and are retried/journaled (`--txpool.journal transactions.rlp`, rejournal 1h). So `eth_sendRawTransaction` can succeed and the tx never land.
- `eth_sendRawTransactionSync` (EIP-7966-style): `--rpc.txsync.defaulttimeout` 20s, `--rpc.txsync.maxtimeout` 1m; timeout error code **4** with tx hash in `data` (`txSyncTimeoutError`).

### Txpool rules
- Router: `core/txpool/txpool.go` `TxPool.Add` splits into subpools: `legacypool` (types 0,1,2,4) and `blobpool` (type 3). Shared stateless validation: `core/txpool/validation.go` `ValidateTransaction`, `ValidateTransactionWithState`.
- Minimum tip: pool `gasTip` initialised from `--txpool.pricelimit` (default **1** wei), not from `--miner.gasprice` (default 0.001 gwei = 1e6 wei, only affects block building); `miner_setGasPrice` updates both. Below -> `transaction gas price below minimum: gas tip cap X, minimum needed Y`.
- Legacy pool defaults (`legacypool.DefaultConfig`): pricebump **10%** (`--txpool.pricebump`), accountslots **16** executable per account (`--txpool.accountslots`), globalslots **5120** (4096+1024), accountqueue **64**, globalqueue **1024**, lifetime **3h** for queued txs; max tx size 128 KiB (4 slots of 32 KiB, `txMaxSize`). Replacement requires BOTH feeCap and tipCap >= old * 1.10 (and strictly higher) else `replacement transaction underpriced` (`list.go` `Add`). Nonce gaps are allowed (go to queue/"queued"), executable go to "pending". When full, underpriced txs rejected (`transaction underpriced`); future txs cannot evict pending (`ErrFutureReplacePending`).
- Set-code (type 4, Prague): requires >= 1 authorization (`set code tx must have at least one authorization tuple`); delegated accounts (or those with pending authorization) may have at most **1 in-flight tx**, no nonce gaps (`ErrInflightTxLimitReached`, `ErrOutOfOrderTxFromDelegated`); an authority with pending txs elsewhere -> `authority already reserved` (`legacypool.validateAuth`). `Reserver` prevents an address being in both subpools (`already reserved`).
- Blob pool (`core/txpool/blobpool/blobpool.go`, `config.go`): `--blobpool.datadir blobpool`, `--blobpool.datacap` 2.5 GiB (10 GiB/4 rollout handicap), pricebump **100%** on feeCap, tipCap AND blobFeeCap (`--blobpool.pricebump`); max **16** txs per account (`maxTxsPerAccount`), max tx size 1 MiB, max blobs/tx `params.BlobTxMaxBlobs` = 6, blobFeeCap >= 1 (`blobTxMinBlobGasPrice`). Only blob txs with sidecar accepted; nonce-gapped blob txs go to a short-lived `gapped` buffer (1 min, max 128 total) and are not announced. Persistence in billy shelves + `limbo` for included-not-finalized blobs. Sparse blobpool (EIP-8070) via `--blobpool.fetchprobability` (cells, custody bitmap; `GetBlobsV4`).
- `txpool_content/status/inspect/contentFrom`: `internal/ethapi/api.go` `TxPoolAPI` (pending vs queued).

### eth_simulateV1
- `internal/ethapi/simulate.go`, `BlockChainAPI.SimulateV1`. Limits: 256 blocks, 5000 calls per block, 10,000 total (`-38026 client limit exceeded`, messages `too many blocks` / `too many calls...`); empty `blockStateCalls` -> `-32602 empty input`. Whole request shares the `--rpc.gascap` budget (`gasBudget`; `RPC gas cap exhausted: need N, remaining M`). Block numbers/timestamps must increase (-38020/-38021); default timestamp step 12s (`timestampIncrement`; check post-Amsterdam if slot-based, unverified); difficulty override after merge rejected. Unknown keys in `blockOverrides`/`stateOverrides` are rejected (`unknown field`). `traceTransfers` emits ETH transfers as logs from `0xEeee...EEeE` (`logtracer.go`); `validation: true` enforces nonce/balance/basefee rules and returns -380xx codes per call; call-level VM errors: `error.code` -32015 (`ErrCodeVMError`), reverts code 3 + data. Block gas limit exceeded -> -38015.

### debug_trace*
- `eth/tracers/api.go`: `traceTransaction`, `traceCall` (+state/block overrides, `txIndex`), `traceBlockByNumber/Hash`, `traceBlock` (RLP), `traceBlockFromFile`, `traceBadBlock`, `traceChain` (subscription), `standardTraceBlockToFile`, `standardTraceBadBlockToFile`, `intermediateRoots`. Config `TraceConfig{ Tracer, Timeout, TracerConfig, + struct-logger opts }`. Default per-tx timeout **5s** (`defaultTraceTimeout`; `timeout` string e.g. "10s"; error `execution timeout`). Genesis not traceable (`genesis is not traceable`). Missing tx -> `transaction not found`. State regenerated by re-executing up to **128** ancestor blocks (`eth/state_accessor.go` `reexecLimit`; fixed, no `reexec` param) else `state not available` (`database.ErrStateUnavailable`... `(reexec=128)`). `traceChain` triedb mem limit 500 MiB.
- Built-in tracers registered via `DefaultDirectory.Register`: `callTracer`, `prestateTracer`, `4byteTracer`, `muxTracer`, `flatCallTracer`, `noopTracer`, `erc7562Tracer`, `keccak256PreimageTracer`, `stateTracer` (`eth/tracers/native/`, `eth/tracers/logger/` for default struct logger + access-list tracer), plus JS tracers (`eth/tracers/js/`, goja) incl. embedded ones in `eth/tracers/js/internal/tracers/*.js`; arbitrary JS code string accepted as `tracer`. Block trace of a whole block returns `[]{txHash, result|error}`.
- `debug` is NOT in the default HTTP/WS modules; enable via `--http.api eth,net,web3,debug,txpool`.

### History and state retention / pruned data
- Chain history (`--history.chain`): `all` (default, `KeepAll`), `postmerge`, `postprague`, `postosaka`, or `<block>:<hash>` (`core/history/historymode.go`). Pruned bodies/receipts -> `pruned history unavailable` (4444). Genesis-to-cutoff headers remain; `earliest` resolves to cutoff.
- Tx index `--history.transactions` default **2,350,000** blocks (0 = all; forced 0 for archive unless set; `cmd/utils/flags.go` `setTransactionHistory`, `core/txindexer.go`). Outside window `eth_getTransactionByHash`/receipt return `null` (or indexing-in-progress error while (re)building).
- State: `--state.scheme path` default; `--gcmode full` (recent ~128 blocks state + path-db state history), `--gcmode archive` = no pruning. `--history.state` default **90,000** blocks (`params.FullImmutabilityThreshold`, only path scheme; 0 = all). `eth_call` etc. on older block: `StateAt` fails, falls back to `HistoricState` (reverse diffs); beyond retention -> `state not available` / `state <root> is not available`. Hash scheme full nodes only keep ~last 128 blocks of state (`missing trie node` style errors) (unverified exact text). Historical state over UBT unsupported (`historical state over ubt is not yet supported`).
- `eth_capabilities` (`internal/ethapi/capabilities.go`, execution-apis PR 755) reports these retention windows (`HistoryRetention`).

## 5. Quirks / deviations
- `earliest` != genesis when history pruned (resolves to `HistoryPruningCutoff`).
- `eth_getLogs`: no result or range limit by default; `--rpc.logquerylimit` limits addresses/topics, not results.
- `eth_sendRawTransaction` can return success for txs held only in the local tracker (temporary rejects).
- `eth_gasPrice` = oracle tip + head base fee; oracle only samples 3 txs/block, percentile 60 of last 20 blocks; capped 500 gwei.
- `pending` block is a locally-built synthetic block (2s cache); pending logs are not supported at all.
- Estimate result is within 1.5% of minimum (error ratio), not exact minimum.
- Non-standard/extra: `eth_baseFee`, `eth_blobBaseFee`, `eth_getStorageValues`, `eth_capabilities`, `eth_config` (EIP-7910), `eth_sendRawTransactionSync`, `eth_getBlockReceipts`, `engine_*WithWitness*`, `engine_executeStatelessPayload*`, `engine_hasBlobs`, `testing_*`, `debug_executionWitness`, `debug_replayBadBlock`.
- Revert errors use code **3** (EIP-1474 style) with `data`; other call failures (`out of gas`, invalid opcode) have code -32000 via plain error (VM errors have `VMError` codes only in simulate).
- Many errors come wrapped with context suffixes (e.g. `err: <msg> (supplied gas N)` from `applyMessageWithEVM`), so match on substrings.
- Engine `getBlobsV1` is rejected post-Osaka with -38005 while V2/V3 return `null` pre-Osaka (opposite directions).
- HTTP and WS share one listener if `--ws.port == --http.port` (`node/node.go` `wsServerForPort`).
- Block numbers must be hex; decimal strings are rejected.

## 7. Docs and versions
- In-repo docs are minimal: `README.md` (flags overview, JSON-RPC/Engine usage, links), `AGENTS.md` (contributor checks: `gofmt`, `make all`, `go run ./build/ci.go test|lint|check_generate`), `docs/postmortems/`, `docs/audits/`, `eth/tracers/internal/tracetest/README.md`, `cmd/workload/README.md`, `SECURITY.md`. The user-facing docs are external (geth.ethereum.org); RPC method docs are NOT in the repo. The source of truth for flags is `cmd/utils/flags.go` (`geth --help`).
- Releases: `vMAJOR.MINOR.PATCH` tags (e.g. `v1.17.10`); `version/version.go` holds the NEXT version with `Meta = "unstable"` on master. Check what a tag contains with `git log v1.17.10..HEAD --oneline -- <path>` and `git tag --contains <sha> --list 'v1.*' --sort=v:refname | head -1`. `git tag` count is ~281 and includes old non-semver tags, so `--sort=-v:refname` without a `v1.*` glob can mislead; `-creatordate` is also unreliable for backported patch releases (e.g. v1.16.x vs v1.17.x ordering), so rely on semver restricted to `v1.*`.
